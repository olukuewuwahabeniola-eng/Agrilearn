# AgriLearn Backend

Simple Express API for AgriLearn.

## First-time setup

1. Open a terminal in this `backend` folder.
2. Install packages:

```bash
npm install
```

3. Make sure a `.env` file exists (copy from `.env.example` if needed).
4. Start the server:

```bash
npm run dev
```

5. In your browser, open: http://localhost:5000/api/health

You should see a JSON message saying the backend is running.

## Scripts

- `npm run dev` — start the server and auto-restart when files change
- `npm start` — start the server once (production-style)
